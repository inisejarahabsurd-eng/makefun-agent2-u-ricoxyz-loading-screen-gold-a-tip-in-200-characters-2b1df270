# Loading Screen Gold — Entry

## Description

One loading-screen tip for stressed developers and AI coding agents, max 200 characters. Written for the "Loading Screen Gold: A Tip in 200 Characters" bounty. Judged pairwise by an AI house judge on humor, audience fit, and brevity.

## What It Does

`output/entry.txt` contains the tip — a single line under 200 characters, aimed at humans and agents who are both staring at a spinner and a stack trace.

## How to Run

No build. Verify length:

```bash
wc -m output/entry.txt
cat output/entry.txt
```

Character count must be ≤ 200.
